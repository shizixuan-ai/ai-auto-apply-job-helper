# 开发日志（Devlog）

> 本项目公开。这里记录开发过程中的**踩坑、决策与教训**——不是变更日志（那是 git log 的活），
> 而是"当时为什么这么想、后来发现错在哪、下次怎么避免"的工程叙事。

## 和其他文档的分工

| 文档 | 记什么 | 视角 |
|------|--------|------|
| `docs/adr/` | 架构**决策**（选了 A 没选 B，为什么） | 决策定稿态 |
| `docs/devlog/` | 开发**过程**中的踩坑与教训（bug 归因、假设证伪、反爬对抗） | 过程叙事、可复盘 |
| `docs/sprints/` | 每个 Sprint 的进展快照 | 阶段进度 |
| `CHANGELOG` / git log | 改了什么 | 变更事实 |

一个经验点如果最终收敛成"以后都这么做"的**决策** → 升级成 ADR，并在这里留链接。

## 怎么加一篇

1. 复制 `TEMPLATE.md` → `NNNN-<kebab-标题>.md`（编号顺延，四位数）。
2. 填完后在下方「索引」加一行。
3. 关联的 ADR / commit hash / 项目规则（如 §3.9）都用链接或短哈希标注，方便回溯。
